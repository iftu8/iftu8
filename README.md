## 👨‍💻 About My Engineering Focus

I don't just write code; I engineer digital ecosystems. Based in Chattogram, Bangladesh, I specialize in designing robust, scalable backend architectures that can handle high-throughput operations without breaking a sweat. 

My current obsession lies in **Zero-Touch Automation**. I build pipelines where **Ruby on Rails** acts as the high-speed monolith for business logic and database orchestration, while **Python** microservices handle heavy AI computations and data synthesis.

*   🔭 **Currently Engineering:** Deep dive into `digital-products` — building institutional command vaults that auto-generate enterprise SOPs, cryptographic engines, and AI architectures using highly automated Ruby & Python pipelines.
*   🛡️ **Security First:** Auditing systems to patch vulnerabilities before they are ever exploited. I treat bugs as unauthorized intruders waiting to be eliminated.
*   ⚡ **Core Stack:** Ruby, Python, PostgreSQL, Redis, Docker, and GitHub Actions.
